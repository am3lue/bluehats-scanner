BlueHats Scanner

Explainable Phishing, Brand Impersonation & Online Scam Detection

Built with transparency

Ideation & Origin Story

When I was making this, only me and GOD knew. But for now, ONLY GOD knows.

  • Concept born from gap in explainable scam detection
  • Vision: flag threats + explain why they're threats
  • License philosophy: honest about knowledge limits

Problem Statement

  • Phishing: Growing threat landscape, users click without understanding risks
  • Brand Impersonation: Increasingly sophisticated attacks
  • Explainability Gap: Most detectors just say "unsafe" without rationale
  • Legal Concerns: Developers need cover for AI/ML decisions

Solution Overview

BlueHats Scanner: full-stack web application with explainable detection + user-friendly interface.

  • Frontend: React + Vite
  • Backend: Express + Node.js
  • Database: LibSQL/Turso
  • Scripts: Feeds, SEO, visual analysis utilities

Key Features

  • Phishing URL detection & analysis
  • Brand impersonation recognition
  • Online scam pattern recognition
  • Explainable AI/ML insights
  • Real-time scanning & reporting
  • Feed updates for threat intelligence
  • SEO & shell analysis capabilities

Architecture & Components

System architecture connecting all modules.

  • Frontend: React components, hooks, pages, styles
  • Backend: Express API, server routes, engine modules
  • Scripts: Prerender, SEO shells, feed updates, visual analysis
  • Data Flow: User input → API analysis → Explainable output → UI display

How It Works (Step-by-Step)

  1. Input: User provides URL, email content, or file to scan
  2. Analysis: Backend engine runs multiple checks (tldts, cheerio, custom patterns)
  3. Scoring: System generates risk score with explanations
  4. Output: Detailed report showing threat categories, reasoning, confidence levels
  5. Feedback: User can report false positives/negatives → feeds update
